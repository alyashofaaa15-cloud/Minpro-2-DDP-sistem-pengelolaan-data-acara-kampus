Nama : Alya Shofa

Nim : 2609116077

Sistem pengelolaan data acara kampus adalah sistem yang digunakan untuk mengatur dan menyimpan data kegiatan kampus agar lebih rapi dan mudah dikelola. Data yang disimpan seperti nama acara, tanggal, tempat, dan keterangan.
Melalui sistem ini, pengguna bisa menambah, melihat, mengubah, dan menghapus data acara. Jadi, sistem ini membantu agar pengelolaan acara kampus lebih mudah, cepat, dan tidak perlu dilakukan secara manual.

<img width="1600" height="1391" alt="WhatsApp Image 2026-10-06 at 16 01 03" src="https://github.com/user-attachments/assets/a2eb7b61-06d1-4552-bef4-8920fedebf54" />

Alur flowchart ini dimulai dari login. Pengguna memasukkan username dan password, lalu sistem mengecek apakah yang masuk adalah admin atau user. Kalau login gagal, pengguna kembali ke halaman login.

Kalau admin berhasil login, admin bisa mengelola acara, seperti menambah acara, melihat acara, mengubah data acara, dan menghapus acara. Saat menambah acara, admin memasukkan nama acara, tanggal, lokasi, kategori, dan kuota peserta. Data tersebut kemudian disimpan.

Kalau user berhasil login, user bisa melihat daftar acara yang tersedia dan melakukan pendaftaran. Setelah memilih acara, sistem akan mengecek kuotanya. Kalau kuota masih tersedia, pendaftaran berhasil. Kalau kuota sudah penuh, sistem menampilkan pemberitahuan bahwa kuota tidak tersedia.

Setelah selesai, baik admin maupun user bisa memilih logout, kemudian proses selesai.
Jadi intinya: admin mengatur data acara, sedangkan user melihat dan mendaftar acara.
